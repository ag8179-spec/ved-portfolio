What I learned in CSS

CSS controls how a page looks. I practised four ways of adding style, each one a little more powerful than the last. This is my real practice code and what it shows in the browser.

Inline CSS

Style written directly inside one tag.

<p style="color: blue; font-size: 30px;">
  This is Inline CSS.
</p>

This is Inline CSS.

Internal CSS

Style written once in a <style> tag inside the head.

<style>
p {
  color: green;
  font-size: 50px;
}
</style>

<p>This is internal CSS.</p>

This is internal CSS.

Element selector

Styles every tag of one type at the same time.

p {
  color: purple;
}

<p>This is a purple paragraph</p>
<p>This one is also purple</p>

This is a purple paragraph

This one is also purple

Class selector

Styles only the tags I choose, using a class name.

.highlight {
  color: orange;
}

<p class="highlight">This is highlighted.</p>
<p>This is normal.</p>

This is highlighted.

This is normal.
